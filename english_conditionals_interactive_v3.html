Zero conditional
Formula
If + present simple → present simple
What it expresses

Use the zero conditional for scientific facts, habits, and things that are always true. The "if" here means the same as "when" or "whenever". Both clauses refer to general reality, not a specific future moment.

You can swap the clauses: "Water boils if you heat it to 100°C" — the comma disappears when the main clause comes first.
Examples
Correct
If you heat ice, it melts.
Incorrect
If you heat ice, it will melt. ✗
If people eat too much sugar, they gain weight.
If I work late, I take a taxi home.
First conditional
Formula
If + present simple → will + infinitive
What it expresses

Use the first conditional for real, possible situations in the future. The speaker genuinely thinks the condition could happen. Common in promises, warnings, and predictions.

Never use will in the if-clause! Also possible: can, may, might, should instead of will in the result clause.
Examples
Correct
If it rains tomorrow, we will cancel the trip.
Incorrect
If it will rain tomorrow… ✗
If she studies hard, she will pass.
If you don't leave now, you will miss the bus.
Second conditional
Formula
If + past simple → would + infinitive
What it expresses

Use the second conditional for imaginary, unlikely, or impossible situations in the present or future. Also used for giving advice with If I were you…

Use were (not was) for all subjects in formal English: "If I were a millionaire…" — this is the subjunctive mood.
Examples
Correct
If I had more time, I would travel the world.
Incorrect
If I would have more time… ✗
If she were taller, she would become a model.
If I were you, I wouldn't say that.
Third conditional
Formula
If + past perfect → would have + past participle
What it expresses

Use the third conditional to imagine a different past — something that did NOT happen. It often expresses regret, criticism, or relief. The situation is impossible to change now.

You can also use could have or might have instead of would have: "If you had called, I might have helped."
Examples
Correct
If she had studied, she would have passed.
Incorrect
If she studied, she would have passed. ✗
If they had left earlier, they wouldn't have missed the flight.
I would have called if I had known your number.
Mixed conditional — type 1
Formula
If + past perfect → would + infinitive
What it expresses

This type connects a past event to a present consequence. The if-clause describes something that did NOT happen in the past; the main clause shows how things would be different right now. Think: 3rd conditional if-clause + 2nd conditional result.

The key signal is a present-time word in the result clause: now, today, currently, at the moment. That word tells you the consequence is in the present, not the past.
Examples
Correct
If I had taken the job, I would be rich now.
Incorrect
If I had taken the job, I would have been rich now. ✗
If she hadn't dropped out, she would be a doctor today.
If he had slept well, he wouldn't feel so tired now.
Mixed conditional — type 2
Formula
If + past simple → would have + past participle
What it expresses

This type connects a permanent present state or quality to a past result. The if-clause describes something not true about the person now; the main clause shows how a past event would have gone differently. Think: 2nd conditional if-clause + 3rd conditional result.

The if-clause often describes a personality trait: "If I were braver…", "If she were more organised…" — the present state is what prevented a different past outcome.
Comparison with Mixed type 1
Mixed type 1 — past → present
If + past perfect → would + inf.

If I had studied medicine,
I would be a doctor now.
Mixed type 2 — present → past
If + past simple → would have + pp

If I were a doctor,
I would have helped him yesterday.
Examples
Correct
If I were braver, I would have spoken up at the meeting.
Incorrect
If I had been braver, I would have spoken up. ✗ (pure 3rd conditional)
If she weren't so shy, she would have applied for the promotion.
If he were more organised, he wouldn't have missed the deadline.
